# «Балдаурен» балалар клубы — лендинг

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · Motion · Lucide.
Шрифты: Montserrat (заголовки) и Nunito (текст) — оба содержат все казахские буквы Ә Ғ Қ Ң Ө Ұ Ү Һ І.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка
```

## Две версии сайта

- `src/components/website/` — Desktop (экраны ≥ 1024px), ориентир 1366 × 768.
- `src/components/mobile-website/` — Mobile (< 1024px), отдельная композиция.
- `src/components/shared/` — общие элементы (эмблема, декор, лайтбокс, карта, переключатель).
- `src/data/kindergarten.ts` — все факты и казахские тексты.

Один URL. Версия выбирается по ширине экрана (`LayoutSwitch`), не по User-Agent: сервер отдаёт
обе композиции, CSS показывает нужную до гидратации, затем лишняя удаляется из DOM.
Изображения скрытой версии не загружаются.

## Фотографии и видео

Положите файлы в `public/images/` и сделайте новый деплой — код менять не нужно:

| Файл | Где появится |
| --- | --- |
| `main-page.jpg` (или `.png/.webp/.mp4`) | Главная секция |
| `main-page2.jpg` (или видео) | «Біздің клуб туралы» |
| любые другие | «Біздің галерея» (по имени файла) |

Для видео можно добавить обложку `<имя>-poster.jpg`. Как фото `main-page` и `main-page2` ложатся
в фигурные рамки (точка фокуса, чтобы не обрезать лица) и их alt-тексты — в `photos`
в `src/data/kindergarten.ts`. Галерея показывает каждое фото в его собственных пропорциях. Пока фото нет, показываются иллюстрации
и аккуратное пустое состояние галереи со ссылкой на Instagram.

Названия, описания и фото групп — в `groups` в `src/data/kindergarten.ts`.

## Деплой на Vercel

Импортируйте проект в Vercel — настройки не нужны. Для своего домена задайте
`NEXT_PUBLIC_SITE_URL=https://ваш-домен.kz` (canonical, Open Graph, sitemap).
